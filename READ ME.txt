RANK CHECKER

Quick Google top 10 checks, run from a dashboard.

THE APP (WINDOWS)
  Download "Rank.Checker_<version>_x64-setup.exe" from the latest release at
  https://github.com/jakemulholland-code/rank_checker/releases/latest
  and run it. Windows SmartScreen warns because the installer isn't
  code-signed: choose More info, then Run anyway. Then open Rank Checker
  from the Start menu (and pin it to the taskbar if you like).

  No Python needed. The app checks for a new version each time it opens and
  offers "Install and restart".

  Results are kept in %APPDATA%\uk.co.paramountdigital.rank-checker\results
  (paste that into the File Explorer address bar). To bring over checks from
  the old version, close the app, then copy history.json and settings.json
  from the old "results" folder into that one.

  Exports (client pages, CSVs, Netlify zips) go to your Downloads folder,
  and File Explorer opens to show each one.

WITHOUT THE APP
  Mac:      double-click "Rank Checker.command"
  Windows:  double-click "Rank Checker.bat"

The dashboard opens in your browser.

USING IT
Enter keywords (one per line) and your
domain, then click Run check. Results appear as each keyword finishes, and
your keywords and domain are remembered for next time.

COMPARING WITH WINCHER
  1. In Wincher, open Keyword Overview and click Export (CSV or Excel).
  2. In Rank Checker, choose "Compare with Wincher" and drop the file in.
  3. Tick the keywords to check (or use the Top 10 / Positions 11 to 20
     buttons), then click Check.
  The results show Wincher's position next to the manual one, biggest gaps
  first. Comparison checks look down to position 20, so allow about 45
  seconds per keyword.

Without the app, a small window stays open while Rank Checker runs. Close it
to shut down.

FIRST TIME ONLY (WITHOUT THE APP)
  You need Python 3.9 or newer: https://www.python.org/downloads/
  (On Windows, tick "Add python.exe to PATH" during install.)
  The first launch then takes a minute or two to set itself up.

  Mac: if it says the file can't be opened, right-click it, choose Open,
  then Open again. You only need to do this once.

SHARING WITH A CLIENT
  Pick a check in the dropdown, then:
  - "Client page" downloads one HTML file you can email or keep.
  - "Netlify site (.zip)" downloads a ready-made website. Go to
    app.netlify.com/drop and drag the zip in to get a link to send the client.
    To update it later, open that site in Netlify, go to Deploys and drag the
    new zip in, so the client's link stays the same.
  Both only include checks for that check's domain, never other clients'.
  The page is hidden from search engines, but anyone with the link can view
  it, so use one Netlify site per client. Add #run=<check id> to the link
  (shown at the bottom of the page) to open a particular check.

GOOD TO KNOW
  - A Chrome window opens during a check (Edge if Chrome isn't installed).
    Leave it open.
  - If Google shows a CAPTCHA, solve it in that Chrome window and the check
    carries on. If Google blocks the check, wait an hour or so.
  - The check pauses between keywords (20 to 40 seconds by default). You can
    change the pause next to the Run button, or click "Skip the wait" while a
    check is pausing. Shorter pauses and large checks are more likely to hit a
    CAPTCHA or a block from Google.
  - Without the app, results are saved in the "results" folder here.
